# Getting started

Northstar Notes is a command-line notebook for course work. Each note is stored as its own plain text file.

Install Northstar Notes with pip: pip install northstar-notes. The version described in this documentation is 2.4.1.

You need Python 3.10 or newer before you install Northstar Notes. Older Python versions are not supported.

Create a notebook named lab-journal with northstar init lab-journal. That command creates a folder called lab-journal and a file named notebook.toml inside it.
