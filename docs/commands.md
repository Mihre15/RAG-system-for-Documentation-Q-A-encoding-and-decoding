# Commands

List every note in the current notebook with northstar list.

The list is sorted by the time the note was last modified, newest first.

Add a note titled Week 3 with northstar add "Week 3". You will be prompted to type the body. Save the note by entering a line that contains only a period.

Search note bodies with northstar search followed by a word, for example northstar search mitochondria. Search is case-insensitive and matches whole words only. It does not search titles.
